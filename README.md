# ParserPon4ik — інформаційно-аналітична система

Проєкт на Python для збору матеріалів з Telegram/RSS/web, зберігання їх у PostgreSQL, аналізу та перегляду через вебпанель FastAPI.

## Що в репозиторії

- `app/` — Python-модулі системи;
- `webui/` — вебсторінки та стилі;
- `database/` — SQL-схема і міграції PostgreSQL;
- `scripts/` і `tools/` — допоміжні сценарії;
- `tests/` — частина тестів;
- `requirements.txt` — залежності Python;
- `.env.example` — приклад конфігурації без справжніх облікових даних.

## Запуск

1. Встановити Python, PostgreSQL та потрібні зовнішні інструменти, які використовує ваш режим роботи.
2. Створити середовище: `py -m venv .venv`.
3. Встановити залежності: `.venv\Scripts\python -m pip install -r requirements.txt`.
4. Створити `.env` за `.env.example`, налаштувати `DATABASE_URL` і свої ключі доступу.
5. Створити базу PostgreSQL та застосувати схему `database/schema.sql` і потрібні міграції.
6. Для локальної вебпанелі скористатися `start_panel.cmd` або командою запуску відповідного модуля.

**Примітка:** це вихідні тексти серверної системи, а не самодостатній демопроєкт. Робоча база з її історичними даними, профілі авторизації, ключі та серверні залежності в GitHub-версію не входять. Деякі функції потребують налаштованих зовнішніх сервісів і повторної авторизації. Повне відновлення на новому сервері не перевірялося.

Не додавайте до репозиторію `.env`, сесії Telegram, звіти користувачів та бази даних із реальними записами.
